## Задание

Дано полутоновое изображение сканированной страницы с напечатанной растрированной (halftone) фотографией. Необходимо подавить на изображении структуру растра, при этом оставив фотографию достаточно чёткой.

Чтение изображения — из файла формата TIFF (без сжатия, несколько strips, Intel и Motorola) реализовано самостоятельно без внешних библиотек.

## Алгоритм

### Шаг 1. Чтение TIFF (собственная реализация)

Реализован полный разбор TIFF-файла без использования внешних библиотек:
- Определение порядка байт: Intel (II, little-endian) или Motorola (MM, big-endian)
- Разбор IFD (Image File Directory): теги ImageWidth, ImageLength, BitsPerSample, Compression, StripOffsets, StripByteCounts
- Сборка изображения из нескольких strips
- Поддержка только несжатых файлов (Compression = 1), 8 бит/пиксель

### Шаг 2. Двумерное преобразование Фурье

- Изображение дополняется нулями до ближайшей степени 2 (2480×3507 → 4096×4096)
- Прямое FFT: построчно + постолбцово
- fftshift: нулевая частота (DC) перемещается в центр спектра

### Шаг 3. Логарифм амплитудного спектра

Вычисляется `log(1 + |F(u,v)|)` для каждой частотной составляющей.  
Порог сегментации: `threshold = mean + 4.5 * std`

### Шаги 4–5. Сегментация и вычисление моментов (лекция 10)

Пороговая сегментация спектра с разметкой 4-связных компонент (BFS).  
Для каждого кластера вычисляются геометрические моменты по формулам лекции 10:

- **M00** — момент 0-го порядка (площадь кластера)
- **cx, cy** — центр масс: `cx = M10/M00`, `cy = M01/M00`
- **mu20, mu02, mu11** — центральные моменты 2-го порядка
- **phi** — угол главной оси инерции: `phi = 0.5 * arctan(2*mu11 / (mu20 - mu02))`

Исключаются пики вблизи осей частот (артефакты краёв страницы).  
Остаются только пики растра, удалённые от обеих осей более чем на 200 пикселей спектра.

### Шаг 6. Главная ось инерции ансамбля пиков (лекция 10)

Центры масс всех найденных пиков рассматриваются как точечное «облако».  
По этому облаку вычисляются моменты, и определяется угол главной оси инерции всего растрового экрана.

### Шаг 7. Notch-фильтр

Каждый пик растра подавляется гауссовой маской в частотной области:

```
weight(d) = 1 - exp(-d² / (2·σ²))
```

При `d = 0` (центр пика): weight = 0 → полное подавление.  
При `d >> σ`: weight ≈ 1 → частоты изображения не затронуты.

Параметр: σ = 50 пикселей спектра.

### Шаг 8–9. Обратное FFT и сохранение

Обратный fftshift, обратное FFT2D, обрезка в диапазон [0, 255].  
Сохранение результата через `NPngProc::writePngFile` (библиотека преподавателя).

### Анализ результатов

**Растровая структура:** 12 пиков, симметричных попарно — 4 основных группы по углам спектра.

**Угол главной оси инерции растра: 44.28°** — растровый экран ориентирован примерно под 45° к горизонтали, что является стандартным углом растрирования для монохромной печати.

**Пространственный период растра: 4.0 пикселя** по обеим осям — соответствует частоте линиатуры растра около 600/4 = 150 lpi при разрешении сканирования 600 dpi.

### Вывод

Notch-фильтр в частотной области эффективно подавляет регулярную растровую структуру: точечный паттерн практически исчезает, при этом содержательная часть изображения (лица, текст) сохраняется с достаточной чёткостью. Метод работает благодаря тому, что растр создаёт узкополосные пики в спектре Фурье, которые можно точечно подавить, не затронув широкополосный спектр фотографического изображения.
