## Задание

Дано полутоновое изображение сканированной страницы с текстом, повёрнутой относительно горизонтали. Определить угол поворота и скорректировать изображение так, чтобы строки текста были горизонтальными.

---

## Алгоритм

1. **Загрузка TIFF** — собственная реализация без внешних библиотек (`tiff_reader`)
2. **2D FFT** — итеративный алгоритм Кули-Тьюки, fftshift для размещения DC в центре
3. **Логарифм амплитудного спектра** — порог = среднее + 4.5·σ
4. **Сегментация пиков** — выбираем пиксели спектра выше порога, исключаем DC-зону и горизонтальную полосу (артефакты краёв страницы)
5. **Взвешенные центральные моменты 2-го порядка** (лекция 10) — вес пикселя пропорционален его яркости в спектре
6. **Главная ось инерции** по формуле из лекции 10:
   ```
   phi = 0.5 * arctan(2*mu11 / (mu20 - mu02))
   ```
   Строки текста создают пики в спектре, вытянутые перпендикулярно строкам. При горизонтальном тексте phi = 90°, угол коррекции = phi − 90°.
7. **Поворот изображения** на найденный угол — билинейная интерполяция
