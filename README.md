## Задания

**Лабораторная работа №2** — Преобразование Фурье  
Реализовать быстрое преобразование Фурье (FFT) для одномерных сигналов и двумерных изображений произвольного размера. Сохранить логарифм амплитудного спектра в PNG (низкие частоты в центре). Показать примеры для смеси синусоид.

**Лабораторная работа №3** — Геометрические преобразования и интерполяция  
Реализовать поворот изображения на произвольный угол с использованием трёх методов интерполяции: метода ближайшего соседа, билинейной и бикубической. Сравнить результаты по качеству и времени работы.

**Лабораторная работа №4** — Свёртка  
Реализовать двумерную свёртку для произвольного ядра. Реализовать ФНЧ и исследовать его на изображениях с гауссовым и импульсным шумом. Реализовать усредняющий фильтр с порогом, ФВЧ лапласиан и LoG, детектирование границ через нулевой переход, фильтр повышения резкости.

**Лабораторная работа №5** — Ранговая фильтрация и морфологические операции  
Реализовать ранговую фильтрацию изображения для произвольной апертуры фильтра. Реализовать фильтр усечённого среднего. Сравнить по критерию PSNR с работой усредняющего и медианного фильтров для фильтрации импульсного и аддитивного гауссового шума. Реализовать для полутоновых изображений морфологические операции эрозии, наращения, открытия, закрытия.

**Лабораторная работа №6** — Сегментация и вычисление признаков  
Реализовать бинаризацию изображения по порогу (алгоритм Оцу). Для бинарного изображения выполнить разметку 4-связных областей. Вычислить геометрические моменты 0-го и 1-го порядков и центральные геометрические моменты 2-го порядка. Определить количество областей с площадью более 30 пикселов, похожих по форме на круг.
