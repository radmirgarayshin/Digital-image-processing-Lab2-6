## Задание

Реализовать бинаризацию изображения по порогу (алгоритм Оцу). Для бинарного изображения выполнить разметку 4-связных областей. Вычислить геометрические моменты 0-го и 1-го порядков и центральные геометрические моменты 2-го порядка. Определить количество областей с площадью более 30 пикселов, похожих по форме на круг.

---

---

## Реализованные алгоритмы (lab6.cpp)

- **otsuThreshold** — алгоритм Оцу: перебор порогов, максимизация межклассовой дисперсии
- **binarize** — бинаризация: пиксели >= порог → 255, иначе 0
- **labelConnectedComponents** — двухпроходная разметка 4-связных областей с Union-Find
- **computeRegionProperties** — вычисление для каждой области:
  - M00 — площадь (момент 0-го порядка)
  - cx, cy — центр масс (моменты 1-го порядка: M10/M00, M01/M00)
  - mu20, mu02, mu11 — центральные моменты 2-го порядка
  - circularity — отношение собственных значений матрицы ковариации (1 = идеальный круг)
- **countCircularRegions** — подсчёт областей с area > minArea и circularity >= порог
- **saveLabeledImage** — сохранение карты меток как grayscale PNG
