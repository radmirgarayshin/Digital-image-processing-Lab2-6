## Задание

Реализовать быстрое преобразование Фурье (FFT) для одномерных сигналов и двумерных изображений произвольного размера. Сохранить логарифм амплитудного спектра в PNG (низкие частоты в центре). Показать примеры для смеси синусоид.

---

## Структура проекта

Код лабораторной работы находится в папке `lab2/`:

```
lab2/

  PngProc.h       — библиотека препода для чтения/записи PNG
  PngProc.cpp     — библиотека препода для чтения/записи PNG
```

---

## Реализованные алгоритмы (lab2.cpp)

- **fft1d** — одномерное быстрое преобразование Фурье (алгоритм Кули-Тьюки, рекурсивный)
- **padToPow2** — дополнение сигнала нулями до ближайшей степени 2
- **fft2d** — двумерное FFT (построчно + по столбцам)
- **saveSpectrum** — сохранение логарифма амплитудного спектра с fftshift (низкие частоты в центре)
- **makeSineSignal** — генерация 1D сигнала из смеси синусоид
- **makeSineImage** — генерация 2D изображения из смеси синусоид

---


## Тесты и результаты

Программа выполняет три теста автоматически:

### Тест 1: 1D FFT смеси синусоид
Сигнал из трёх частот (5, 13, 30 Гц), 256 отсчётов.  
Результат: **spectrum_1d.png** — спектр с пиками на соответствующих частотах.

### Тест 2: 2D FFT изображения из синусоид
Изображение 256×256, смесь трёх 2D синусоид с частотами (3,0), (0,5), (7,4).  
- **sine_image.png** — исходное изображение (решётчатый паттерн)
- **spectrum_2d_sine.png** — спектр: чёткие точки в центре, соответствующие частотам синусоид

### Тест 3: 2D FFT реального изображения (kotik.png)
Реальное фото кота, конвертируется в grayscale.  
- **spectrum_2d_real.png** — спектр: яркое пятно в центре (низкие частоты) и крест — классическая форма спектра реального изображения
