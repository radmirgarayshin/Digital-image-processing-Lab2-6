## Задание

Реализовать поворот изображения на произвольный угол с использованием трёх методов интерполяции: метода ближайшего соседа, билинейной и бикубической. Сравнить результаты по качеству и времени работы.

---

## Структура

Код лабораторной работы находится в папке `lab3/`:

```
lab3/
  main.cpp        — точка входа, запуск всех тестов
  lab3.h          — объявления функций
  lab3.cpp        — реализация алгоритмов поворота и интерполяции
  kotik.png       — тестовое изображение
```

Библиотека для чтения/записи PNG (`PngProc.h`, `PngProc.cpp`) находится в папке `pngtest/`, библиотеки `libpng/` и `zlib/` — в соответствующих папках проекта.

---

## Реализованные алгоритмы (lab3.cpp)

- **rotateImage** — поворот изображения на произвольный угол методом обратного отображения
- **getRotatedSize** — вычисление размера выходного изображения после поворота
- **nearestNeighbor** — интерполяция методом ближайшего соседа
- **bilinear** — билинейная интерполяция
- **bicubic** — бикубическая интерполяция (ядро Кейса, a=-0.5)
