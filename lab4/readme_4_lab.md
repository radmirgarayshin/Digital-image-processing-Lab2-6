## Задание

Реализовать двумерную свёртку для произвольного ядра. Реализовать ФНЧ и исследовать его на изображениях с гауссовым и импульсным шумом. Реализовать усредняющий фильтр с порогом, ФВЧ лапласиан и LoG, детектирование границ через нулевой переход, фильтр повышения резкости.

---

## Структура

Код лабораторной работы находится в папке `lab4/`:

```
lab4/
  main.cpp        — точка входа, запуск всех тестов
  lab4.h          — объявления функций
  lab4.cpp        — реализация всех алгоритмов
  kotik.png       — тестовое изображение
```

Библиотека для чтения/записи PNG (`PngProc.h`, `PngProc.cpp`) находится в папке `pngtest/`.

---

## Реализованные алгоритмы (lab4.cpp)

- **convolve2d** — двумерная свёртка для произвольного ядра любого размера
- **lowPassFilter** — ФНЧ (усредняющий фильтр box filter)
- **thresholdAvgFilter** — усредняющий фильтр с порогом (усредняет только пиксели близкие к центральному)
- **addImpulseNoise** — импульсный шум (salt & pepper)
- **laplacianFilter** — ФВЧ лапласиан (ядро 3×3, со сдвигом 128)
- **logFilter** — ФВЧ LoG (лапласиан гауссиана, параметр sigma)
- **zeroCrossing** — детектирование границ через поиск нулевого перехода LoG
- **sharpenFilter** — повышение резкости (unsharp masking)
